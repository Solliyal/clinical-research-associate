# Präsentation: Nicht geradlinig — und trotzdem angekommen

Vortrag (ca. 15 Minuten) für Studierende im Master Biowissenschaften über Berufswege
nach dem Studium — am Beispiel des Wegs in die klinische Forschung als
Clinical Research Associate (CRA).

## Öffnen

`praesentation.html` per Doppelklick im Browser öffnen. Keine Installation, kein
Internet nötig — Bilder, Schriften und Skripte stecken in der einen Datei.

## Steuerung

| Taste | Funktion |
|---|---|
| `→` `↓` `Leertaste` | nächste Slide |
| `←` `↑` | vorherige Slide |
| `Pos1` / `Ende` | erste / letzte Slide |
| `1`–`9` | direkt zu Slide springen |
| `N` | Sprechernotizen ein-/ausblenden |
| `O` | Übersicht aller Slides |
| `T` / `R` | 15-Minuten-Timer starten bzw. pausieren / zurücksetzen |
| `F` | Vollbild |
| `?` / `Esc` | Hilfe / alles schließen |

Alternativ links bzw. rechts an den Rand klicken oder auf dem Tablet wischen.

## Vor dem Vortrag anpassen

- **Slide 17:** Kontaktdaten eintragen (im HTML nach `KONTAKT ANPASSEN` suchen).

Die Sprechernotizen (`N`) enthalten zu jeder Slide Zeitmarken und Hinweise, was
gesagt werden sollte.
